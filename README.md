## About

Current implementation just counts time and always has 25 mines on a 10x10 grid.

No losing just yet, and number art is unfinished, but as long as you don't lose can enjoy random games on each restart.

Don't judge too hard, was my first ever C++ / SFML project.

## Before Running

Ensure that both SFML 3.0 and C++20 are downloaded.

To download SFML follow the instruction under **Getting Started** [found here](https://www.sfml-dev.org/tutorials/3.0/).

## How To Run

Within root directory run `make` followed by `./bin/minesweeper`.

To clean directory use `make clean`.
